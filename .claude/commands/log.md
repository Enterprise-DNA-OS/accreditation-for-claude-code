# /log

Read the record first. Obtain the named operator and exact values from the request. Inspect entities.json for valid fields. Never invent evidence, a review, a conflict declaration or a committee decision. Apply the requested change and reread the record. A name is a recorded attribution, not authenticated identity.

```bash
npm run accreditation -- log --kind=<entity> --ref=<code-or-name> --note=<note> --actor=<operator> --json
```

Use the human output when useful. Ambiguous names stop and list choices. Check the command exit status before reporting success.
