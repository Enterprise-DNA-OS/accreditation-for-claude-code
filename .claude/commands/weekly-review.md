# /weekly-review

Run the weekly review, which combines attention, cycle-review, committee-agenda and renewals-due. Present evidence gaps and overdue actions first, then committee-ready cycles and approaching renewals. Name the responsible owner. Record requested follow-up through /log or /update.

```bash
npm run accreditation -- weekly-review --json
```

Use the human output when useful. Ambiguous names stop and list choices. Check the command exit status before reporting success.
