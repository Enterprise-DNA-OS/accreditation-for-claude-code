# /draft-committee-pack

Read the cycle, requirements, evidence, findings and decision history first. Generate the draft and present the local file link. Check the intended recipient and wording with the operator. Nothing sends or grants accreditation.

```bash
npm run accreditation -- draft-committee-pack --ref=<cycle-code> --json
```

Use the human output when useful. Ambiguous names stop and list choices. Check the command exit status before reporting success.
