# Why no application front end

The operator asks for the cycle review, evidence gaps or a committee pack. The coding agent runs the CLI against the database and explains the result. That is enough for a small internal accreditation office to organise records, plan visits and prepare committee papers.

Read-only HTML snapshots are files, not a hosted application. They have no forms, action buttons, sign-in or server. They become stale when the database changes. Regenerate them before a meeting. Keep sensitive reports in private storage.

ARMATURE offers external stakeholder portals, configurable forms and connected workflows. This free base does not provide applicant self-service, mobile evidence capture, offline synchronization, document storage, notifications or access management. If your work depends on those, Enterprise DNA scopes and builds them into your version before a switch. The database supports internal recordkeeping today. It is not a claim of whole-platform parity.

Use brand.json for your name, logo path and colours. npm run docs and npm run view write branded HTML. A browser can print the documents. /new-view adds a read-only report. /customise adds fields or changes your internal rules with migrations and tests.
