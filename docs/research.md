The landing page therefore contains no dollar figure.

Buyer and search scores are deliberately modest: the vendor confirms ANZ operations but no Enterprise DNA customer purchase or search-volume dataset was verified. Local customer and CRM documents searched this run supplied no matching customer record. No live customer database was accessed.

Other candidates: Questionmark exam administration, 3/3/2/3/2/3 = 16, rejected because secure assessment delivery needs a candidate interface outside this build's scope. Jirav financial planning and IndySoft calibration were not eligible: their families are already built. ARMATURE's import score is 2 because a native export exists but requires conversion and mapping. No undocumented CSV headers are presented as vendor facts.
